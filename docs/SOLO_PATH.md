# Solo / small-team priority (Appendix و)

Do **not** start the next line until the previous one works.

1. **Map with ports** (Days 1–2) — this *is* the product face.
2. **Simulator + WS + Store** (Day 3).
3. **Detector + Correlator + RCA** with tests (Days 5–7).
4. **Incident panel + Approve/Reject + Timeline** (Days 6–8).
5. **AlertStorm + Stopwatch** (Day 9) — the wow beat.
6. **Live lab for one scenario only** (uplink congestion).
7. Everything else is additive.

## Explicit note (Infrastructure & Cloud track)

Judges usually reward a **real lab**. Simulation alone can still be an excellent product, but **at least one live scenario** strongly improves odds for first place. If the lab is hard alone, borrow a network engineer for Days 2 and 5.

## Closing line

Build the map first → one moving number → one incident → one correct root → approval. End every day with a tag and green tests. Pitch on **numbers you measured** (`docs/RESULTS.md`).
